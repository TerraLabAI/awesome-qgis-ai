# Contributing

One line per entry: `- [Name](link) by Author: what it does, how it gets a model.`

- Say if you are the maker.
- Link to the plugin page or the source, not a landing page that hides it.
- Entries must be about QGIS and AI (plugins, servers, benchmarks, papers).
- No ranking, no "best". We merge a working link with an honest line.
